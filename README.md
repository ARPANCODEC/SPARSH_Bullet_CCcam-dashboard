# 📹 5G IP Camera Streamlit Dashboard

This project is a **Streamlit-based interactive dashboard** designed to capture, stream, and analyze live video feeds from **8MP 5G IP bullet cameras** using the **RTSP protocol**.  

It provides a clean, user-friendly interface that allows users to:
- 🔴 **Stream live video** from IP cameras
- 📸 **Capture images** from the live feed
- 🎥 **Record video clips** for offline use
- 🎛 **Control playback** and manage camera streams in real time  

Built with **OpenCV** and **Streamlit**, this project is ideal for:
- Surveillance and security systems  
- Computer vision research  
- Smart city and IoT applications  
- Academic projects  

---

## 🚀 Features
- Real-time video streaming via RTSP  
- One-click **snapshot capture** (saved as `.jpg`)  
- Video recording support (saved as `.mp4`)  
- Simple, **intuitive Streamlit UI** with buttons & interactive layout  
- Cross-platform: works on **Windows, Linux, Mac**
