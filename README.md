📹 5G IP Camera Flask Dashboard
This project is a Flask-based interactive dashboard designed to capture, stream, and analyze live video feeds from 8MP 5G IP bullet cameras using the RTSP protocol.

It provides a clean, user-friendly interface that allows users to:

🔴 Stream live video from IP cameras

📸 Capture images from the live feed with metadata

🎥 Record video clips for offline use

👥 User authentication with admin and user roles

🔐 Role-based access control for security

📊 Gallery management for captured media

Built with OpenCV and Flask, this project is ideal for:

Surveillance and security systems

Computer vision research

Smart city and IoT applications

Academic projects

🚀 Features
Real-time video streaming via RTSP

One-click snapshot capture with metadata (saved as .jpg)

Video recording support (saved as .mp4)

User authentication system with secure password hashing

Admin panel for user management

CSV logging of all captured images with metadata

Simple, intuitive web UI with Bootstrap styling

Cross-platform: works on Windows, Linux, Mac

🔧 Technical Stack
Backend: Flask (Python web framework)

Computer Vision: OpenCV

Authentication: Werkzeug security

Frontend: HTML5, Bootstrap, Jinja2 templating

Data Storage: CSV files for users and metadata

Video Processing: OpenCV with H.264/MP4V codecs

👥 User Roles
Admin Users
Add, view, and remove users

Access system information and statistics

Full access to all camera functionalities

Regular Users
Stream live video feeds

Capture images with metadata

Record video clips

Access gallery and download media
